# The Deichlers organization profile

The public GitHub organization overview is maintained in
[profile/README.md](profile/README.md).

Brand artwork is stored locally under `profile/assets/` so the profile does not
depend on assets hosted in a private repository.

Keep this repository limited to profile presentation. Do not add organization-wide
workflow templates, default community policies, infrastructure configuration,
credentials, internal addresses, or service data without a separate review.

Links to private repositories are intentional and labeled as access-restricted.
They do not change those repositories' visibility.
